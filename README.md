Customer Segmentation and Retail Revenue Analysis
Project Overview

This project analyzes online retail transaction data to understand sales performance, customer behavior, and revenue trends. Customer segmentation is performed using RFM (Recency, Frequency, Monetary) analysis.

The project uses Python libraries for data cleaning, analysis, visualization, and customer segmentation.

Technologies Used
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

Objectives
Clean and prepare retail transaction data
Analyze overall business performance
Calculate key business KPIs
Identify top revenue-generating countries
Analyze monthly revenue trends
Perform RFM analysis
Segment customers into Low Value, Medium Value, and High Value groups

Key Business KPIs
Total Revenue: 8,887,208.89
Total Orders: 18,532
Total Customers: 4,338
Total Products: 3,665

Key Insights
The United Kingdom generated the highest revenue.
November 2011 was the highest revenue month, generating approximately 1.16 million.
February 2011 was the lowest revenue month.
Customer behavior was analyzed using Recency, Frequency, and Monetary metrics.
Customers were segmented into Low Value, Medium Value, and High Value groups.
Customer Segmentation

RFM analysis was used to evaluate customer value:
Recency: Number of days since the customer's last purchase
Frequency: Number of unique orders placed
Monetary: Total amount spent by the customer

Conclusion

This project demonstrates an end-to-end data analysis workflow using Python, from data cleaning and exploratory data analysis to RFM-based customer segmentation. The analysis provides insights into revenue trends, customer behavior, and customer value to support data-driven business decisions.
